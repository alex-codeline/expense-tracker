## Название - Трекер расходов. Помогает считать и понимать количество ваших расходов по категориям и количество расходов в целом.

## Возможности
1. Добавление расхода - категория расхода,сумма,а также описание по необходимости
2. Показ всех расходов - по списку: расход-сумма-описание
3. Итог всех расходов
4. Итог расходов по одной из категорий
5. Список всех существующих категорий 
0. Выход из меню

## Запускается через файл main.py
